# E-Commerce Sales & Customer Analysis

## Project Overview

This project analyzes a synthetic e-commerce dataset using MySQL and SQL.

The objective is to explore sales performance and customer purchasing behavior using a relational database and SQL queries.

## Tools & Technologies

- MySQL
- SQL
- DataGrip

## Database Structure

The database contains five main tables:

- `customers`
- `orders`
- `order_items`
- `products`
- `categories`

## Dataset

The synthetic dataset contains:

- 10 categories
- 100 products
- 1,000 customers
- 5,000 orders
- 14,930 order items

## Analysis Performed

### Sales Analysis

- Total Gross Sales
- Total Discounts
- Net Revenue
- Total Units Sold
- Average Order Value
- Revenue by Category
- Revenue by Payment Method


### Customer Analysis

- Total Customers
- Customers Who Have Placed Orders
- Repeat Customers
- Top 10 Customers by Revenue

## SQL Concepts Used

- SELECT
- Aggregate Functions
- COUNT
- SUM
- GROUP BY
- HAVING
- ORDER BY
- JOIN
- CASE
- Subqueries
- COUNT(DISTINCT)

## Project Objective

The project demonstrates practical SQL skills for analyzing business data, working with relational tables, and extracting meaningful insights from e-commerce data.
